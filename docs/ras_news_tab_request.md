# RAS 쪽 Claude Code에게 보낼 요청문

아래 "요청문" 전체를 RAS 프로젝트의 Claude Code 세션에 붙여 넣고, `api.md` 파일을 함께 첨부한다.
토큰 값은 붙여 넣지 않는다 — RAS의 `.env`에 직접 넣는다.

---

## 요청문

RAS에 **뉴스 탭**을 추가해 주세요. 데이터는 집 내부망의 미니PC가 제공하는 **읽기 전용 REST API**에서 가져옵니다.
API 명세는 첨부한 `api.md`입니다. 먼저 RAS의 현재 구조(GUI 프레임워크, 탭 구성, 설정·.env 읽는 방식, 비동기 처리 방식)를
살펴보고, 기존 코드 스타일에 맞춰 구현 계획을 짧게 보여 준 뒤 진행해 주세요.

### 배경
- 미니PC가 매일 07:00경 전일 15:30 이후의 뉴스(네이버 시황·전망, 정부 정책브리핑)와 DART 공시를 수집하고,
  종목별 호재 강도(1~5)를 채점해 둡니다. 16:10에는 채점 종목의 주가 반응을 기록합니다.
- RAS는 이걸 **조회만** 합니다. 이 데이터로 주문을 내거나 자동매매 로직에 연결하지 마세요(범위 밖).

### 연결 설정
- RAS `.env`에 두 값을 추가하고 코드에서 읽어 주세요. `.env.example`에는 키 이름만 넣습니다.
  ```
  STOCK_NEWS_API=http://192.168.0.12:8770
  STOCK_NEWS_API_TOKEN=          # 사용자가 직접 입력
  ```
- 모든 요청에 `Authorization: Bearer <토큰>` 헤더. 토큰은 로그·예외 메시지·화면에 출력하지 않습니다.
- 타임아웃 10초. 연결 실패·401·403이면 탭 안에 원인을 한 줄로 보여 주고(예: "미니PC에 연결할 수 없음",
  "토큰 불일치") 프로그램의 다른 기능은 영향받지 않게 합니다.
- 네트워크 호출은 GUI 스레드를 막지 않게 RAS의 기존 비동기/스레드 방식으로 처리합니다.
- 마지막 정상 응답을 로컬 캐시(파일)로 저장해, 미니PC에 연결이 안 될 때는 캐시를 "(오프라인 — HH:MM 기준)" 표시와 함께 보여 줍니다.
- 데이터는 평일 07:15와 16:10 이후에만 바뀝니다. 자동 새로고침은 10분 간격 이상 + 수동 새로고침 버튼.

### 화면 구성 (뉴스 탭 안의 하위 영역)
1. **오늘의 리포트** — `GET /api/report/latest` (날짜 선택: `GET /api/dates`)
   - 상단: 대상 시간대, 호재/악재 종목 수, `warnings`가 있으면 눈에 띄게 경고 표시
   - 호재 순위표: 순위, 종목명(코드), 강도 `final`, 근거 태그 `basis`([공시]/[뉴스]/[정책]), 재료 유형 `category_name`, 재료 `material`
   - 행 선택 시 상세: 항목별 점수와 근거(`factors`, null 항목은 "해당 없음"), `caution`, 원문 링크(`sources`, 클릭 시 기본 브라우저)
   - 주의 종목(`bearish`) 목록은 따로
   - "강도는 재료 세기이며 매수 추천이 아님" 문구를 표 아래 작게 표시
2. **뉴스** — `GET /api/news`
   - 필터: 출처(전체/네이버/정책), 기간(기본 최근 2일), 검색어, 종목코드
   - 목록: 시각, 출처, 언론사, 제목. 선택 시 `GET /api/news/{id}`로 본문과 관련 채점 종목 표시, 원문 링크
   - `limit`/`offset`으로 페이지 넘김(또는 더 보기)
3. **공시** — `GET /api/disclosures`
   - 필터: 날짜, 종목코드, 검색어, 주요 공시만(`major=1`)
   - 목록: 접수 시각(없으면 날짜만), 회사명, 공시명, 신호(buy ▲ / sell ▼). 선택 시 `GET /api/disclosures/{rcept_no}` 본문
4. **종목 조회** — `GET /api/stock/{code}`
   - RAS에 이미 종목을 선택하는 화면이 있으면, 거기서 이 탭의 종목 조회로 넘어올 수 있게 연결(가능한 경우만)
   - 채점 이력과 주가 반응(`reaction`: 시초가 갭, 시가→종가, 지수 대비 초과, 1·3·5일 수익률 — 비율은 소수이므로 %로 변환), 테마·편입 사유, 최근 공시·뉴스

### 구현 원칙
- 기존 RAS 코드 스타일과 의존성을 따르고, 새 라이브러리는 꼭 필요할 때만(먼저 물어보기).
- API 클라이언트는 별도 모듈 한 개(예: `stock_news_client.py`)로 분리해 화면 코드와 나눕니다.
- 응답 JSON에 없는 필드는 화면에서 빈칸으로 처리(앞으로 필드가 늘어날 수 있음). `api_version`이 1이 아니면 경고만 표시.
- 테스트: API 클라이언트는 응답 예시(api.md)로 단위 테스트, 실제 연결은 `GET /api/health`로 확인.
- 끝나면 사용자가 할 일(.env에 토큰 넣기 등)과 확인 방법을 정리해 주세요.

## 추가 요청문 (종목 검색 — 2026-11-13 추가)

미니PC API에 종목 검색 `GET /api/stocks?q=검색어`가 추가됐습니다(갱신된 `api.md` 첨부).
뉴스 탭에 **종목 검색창**을 넣어 주세요.
- 입력 2글자 이상(숫자는 3자리 이상)부터 0.3초 디바운스 후 `/api/stocks?q=…&limit=10`으로 자동완성 목록 표시:
  종목명(코드) · 시장 · 최근 채점(`last_score`가 있으면 "11-13 호재 4" 같은 꼬리표)
- 종목을 고르면 종목 조회 화면(`/api/stock/{code}`)으로 이동하고, 기간 선택(기본 최근 7일)으로
  `/api/news?stock={code}&from=…`, `/api/disclosures?stock={code}&from=…`를 함께 보여 주세요.
- 결과가 없으면 "저장된 뉴스 없음 — 시황·전망·정책 기사만 수집(2026-11-11부터)" 안내를 표시해 주세요.

## 추가 요청문 (저녁 종가매매 리포트 — 2026-11-13 추가)

미니PC가 평일 저녁에 **종가매매 리포트**도 만듭니다(당일 15:30~19:30 공시·뉴스 + NXT 시간외 시세, 19:35~19:45 갱신).
미니PC API에서 `session=evening`으로 조회할 수 있게 됐습니다(갱신된 `api.md` 첨부 — "아침 / 저녁 리포트" 절과 `evening_quote`).
RAS 뉴스 탭을 아래처럼 고쳐 주세요. 이 데이터로 주문을 내거나 자동매매에 연결하지 않습니다(조회 전용).

1. **리포트 선택 전환**: '오늘의 리포트' 영역에 [아침 장전] / [저녁 종가매매] 전환(탭 또는 토글)
   - 기본값: 07:00~19:34는 아침, 19:35~다음날 06:59는 저녁 리포트를 먼저 보여 주기
     (저녁 리포트는 그날 밤과 다음날 NXT 프리마켓(08:00) 전에 보는 용도)
   - 날짜 목록은 `GET /api/dates?session=evening`, 본문은 `GET /api/report/latest?session=evening`
   - `/api/health`의 `latest_evening_report`로 오늘 저녁 리포트가 나왔는지 확인(없으면 "19:45 전후 갱신 예정" 안내)
2. **저녁 순위표 열 추가**(`evening_quote`): KRX 종가 · 지금(NXT) 가격 · **시간외 등락%** · 공시 후 등락% · 시간외 거래대금 · NXT 가능
   - `nxt_enabled == false`면 행을 흐리게 하고 "NXT 불가(애프터마켓 매수 불가)" 표시
   - `as_of`(시세 기준 시각)를 표 위에 "19:31 기준 시세"처럼 표시 — 실시간 시세가 아님을 분명히
   - **단위 주의**: `evening_quote`의 %값은 이미 % 단위(6.0 = 6%). 다른 엔드포인트의 비율(0.035 = 3.5%)과 섞지 말 것
3. **간이 리포트 표시**: `fallback == true`면 상단에 경고 배너("Claude 채점 미완료 — 객관 지표 간이 리포트",
   `fallback_reason`), `final`이 null이면 점수 칸 "-"
4. **종목 조회 화면**: `GET /api/stock/{code}` 응답의 `evening_scores`(저녁 리포트 이력)를 아침 채점 이력 옆에 표시
   - `next_day`(진입가 대비 다음날 시가·고가·종가 수익률, 소수 비율)를 %로 변환해 보여 주기. null이면 "집계 전"
5. 자동 새로고침: 19:35~19:50 사이에는 2분 간격으로 저녁 리포트를 다시 조회(그 외 시간은 기존 10분 이상 간격 유지)
6. 기존 아침 리포트 화면·필드는 바뀌지 않습니다(`session` 생략 = 아침). 없는 필드는 빈칸 처리 원칙 유지.
